# ErgenOS Website

Official landing page for ErgenOS.

The site is fully static and designed for GitHub Pages. Open `index.html`
directly or serve the repository directory with any local HTTP server.

English pages live in the repository root. Complete Polish counterparts are
available under `pl/`, with a page-aware language switcher and `hreflang`
metadata on every page.

## Documentation

Visit the [ErgenOS Wiki](https://ergenossw.github.io/ErgenOS-Wiki/) for installation, system administration, security, recovery, hardware and troubleshooting guides. Available in [English](https://ergenossw.github.io/ErgenOS-Wiki/) and [Polish](https://ergenossw.github.io/ErgenOS-Wiki/pl/).

## Publishing

Publish the `main` branch from the repository root with GitHub Pages.
