Secure Boot setup.

ErgenOS can use Microsoft-signed shim and your own Machine Owner Key without replacing the firmware keys.

Before you begin: the ErgenOS 1.0 installation ISO does not currently boot with Secure Boot enabled. Install ErgenOS normally with Secure Boot disabled, then follow this guide from the installed system.

Test coverage: this workflow has been validated with QEMU/OVMF and on a physical Lenovo ThinkPad. Firmware interfaces differ between manufacturers, so keep your firmware recovery options and important data available.

  1. 1. Update ErgenOS and install the tool

    Install the signed package from the official ErgenOS repository.

    sudo pacman -Syu ergenos-secureboot

  2. 2. Run the safety check

    Confirm that the system uses UEFI, the EFI System Partition is available and all required components can be prepared.

    sudo ergenos-secureboot enable --dry-run

    Continue only when the command reports that the preflight check passed.

  3. 3. Prepare Secure Boot

    Create the ErgenOS Machine Owner Key, sign the kernel, GRUB and installed DKMS modules, and create the separate ErgenOS Secure Boot entry.

    sudo ergenos-secureboot enable

    Choose a temporary password when prompted. You will use it once in MokManager during the next boot.

  4. 4. Enrol the Machine Owner Key

    Restart through the ErgenOS Secure Boot entry. In MokManager choose Enroll MOK, continue, confirm the key and enter the temporary password from the previous step. Then reboot.

  5. 5. Enable Secure Boot in the firmware

    Open the computer's UEFI settings and enable Secure Boot in its standard or default-key mode. Do not clear or replace the platform keys. Save the settings and boot ErgenOS Secure Boot.

  6. 6. Verify the result

    Complete configuration and verify the entire boot chain.

    sudo ergenos-secureboot finalize sudo ergenos-secureboot check mokutil --sb-state

    The expected state is active, and mokutil should report SecureBoot enabled.

After kernel, GRUB or DKMS updates: ErgenOS hooks refresh the signed components automatically. You can also run sudo ergenos-secureboot refresh manually and verify them with sudo ergenos-secureboot check.

Need to remove it? First run sudo ergenos-secureboot remove-mok, confirm removal in MokManager, disable Secure Boot in the firmware, and then run sudo ergenos-secureboot disable. The package blocks unsafe removal while support is still active.
