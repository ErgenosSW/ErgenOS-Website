Secure Boot w ErgenOS.

Skonfiguruj Secure Boot za pomocą shim podpisanego przez Microsoft i własnego klucza MOK — bez wymiany kluczy zapisanych w UEFI.

Zanim zaczniesz: instalacyjne ISO ErgenOS 1.0 nie uruchamia się jeszcze przy włączonym Secure Boot. Najpierw zainstaluj system z wyłączoną funkcją, a dopiero później wykonaj poniższe kroki.

Na czym to sprawdziliśmy: procedura działa na QEMU/OVMF oraz fizycznym Lenovo ThinkPadzie. Ustawienia UEFI różnią się w zależności od producenta, dlatego przed rozpoczęciem zabezpiecz ważne dane.

  1. 1. Zaktualizuj ErgenOS i zainstaluj narzędzie

    Zainstaluj podpisany pakiet z oficjalnego repozytorium ErgenOS.

    sudo pacman -Syu ergenos-secureboot

  2. 2. Sprawdź, czy system jest gotowy

    Narzędzie sprawdzi tryb UEFI, dostępność partycji EFI i wszystkie potrzebne składniki.

    sudo ergenos-secureboot enable --dry-run

    Przejdź dalej tylko wtedy, gdy test zakończy się powodzeniem.

  3. 3. Przygotuj Secure Boot

    Utwórz ErgenOS Machine Owner Key, podpisz jądro, GRUB i zainstalowane moduły DKMS oraz utwórz osobną pozycję ErgenOS Secure Boot.

    sudo ergenos-secureboot enable

    Po wyświetleniu monitu wybierz tymczasowe hasło rejestracji. Zostanie użyte tylko raz przez MokManager podczas następnego uruchomienia; nie jest to hasło systemowe i nie zastępuje ani nie ujawnia prywatnego klucza podpisującego.

  4. 4. Dodaj klucz MOK

    Uruchom komputer ponownie przez pozycję ErgenOS Secure Boot. W MokManager wybierz Enroll MOK, potwierdź klucz i wpisz tymczasowe hasło z poprzedniego kroku. Następnie uruchom komputer ponownie.

  5. 5. Włącz Secure Boot w firmware

    Otwórz ustawienia UEFI komputera i włącz Secure Boot w trybie standardowym lub z domyślnymi kluczami. Nie usuwaj ani nie zastępuj kluczy platformy. Zapisz ustawienia i uruchom pozycję ErgenOS Secure Boot.

  6. 6. Zweryfikuj wynik

    Dokończ konfigurację i sprawdź cały łańcuch rozruchowy.

    sudo ergenos-secureboot finalize
sudo ergenos-secureboot check
mokutil --sb-state

    Oczekiwany stan to active, a mokutil powinien wyświetlić SecureBoot enabled.

Po aktualizacjach: dołączone hooki automatycznie obsługują aktualizacje jądra i GRUB-a. Driver Manager w ErgenPac odświeża też ErgenOS Secure Boot po instalacji sterowników DKMS. Jeśli zainstalujesz moduł DKMS inną metodą, na przykład sterownik NVIDIA albo moduł Wi-Fi Broadcom, wykonaj sudo ergenos-secureboot refresh i sprawdź wynik poleceniem sudo ergenos-secureboot check.

Chcesz usunąć konfigurację? Najpierw wykonaj sudo ergenos-secureboot remove-mok, potwierdź usunięcie w MokManager, wyłącz Secure Boot w firmware, a następnie wykonaj sudo ergenos-secureboot disable. Pakiet blokuje niebezpieczne usunięcie, dopóki obsługa pozostaje aktywna.
