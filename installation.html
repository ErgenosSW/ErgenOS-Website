Installation guide

From ISO to your desktop.

A short guide for installing ErgenOS 1.1 on a modern UEFI computer.

  1. 1. Download the ISO parts

    Download both numbered ISO parts and SHA256SUMS-1.1.0 from the ErgenOS 1.1 GitHub release, then join them with cat ergenos-1.1.0-x86_64.iso.part-* > ergenos-1.1.0-x86_64.iso. The complete image is 2.51 GiB.

  2. 2. Verify the image

    Compare the SHA-256 checksum before writing the image to a USB drive.

    echo "460c2ab349681cef4922ebba35b180b24f7a17e7182dbf23cc7c99b13b1fdcce ergenos-1.1.0-x86_64.iso" | sha256sum -c -

  3. 3. Create the installation USB

    Use Rufus or Etcher on Windows, or GNOME Disks on Linux. Select the downloaded ISO and the correct USB drive. Writing the image erases that USB drive.

  4. 4. Boot in UEFI mode

    Restart the computer, open its boot menu and select the USB drive's UEFI entry. The ErgenOS 1.1 ISO currently requires Secure Boot to be disabled during installation.

  5. 5. Install with Calamares

    Open Install ErgenOS, select your language, keyboard, disk layout and user account, then review the summary before starting installation. Back up important data before changing disk partitions.

  6. 6. Restart, update and check drivers

    Remove the USB drive, boot ErgenOS and use ErgenPac to install system updates. Open Driver Manager to detect the processor and graphics hardware and install any missing recommended packages. If you want to enable Secure Boot afterwards, follow the separate setup guide.
